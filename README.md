# Prepress Tools – cập nhật tự động

Kho này chứa bản cập nhật cho Prepress Tools (plugin prepress cho Adobe Acrobat Pro + chương trình bù bleed AI chạy nền).

- `manifest.txt`: phiên bản mới nhất. Chương trình nền trên mỗi máy đọc file này 4 giờ một lần.
- `files/<phiên bản>/`: các file của từng bản (đã kiểm tra mã SHA-256 trước khi thay).

Bộ cài đầy đủ (PrepressTools_Setup) được phát riêng, không đặt trong kho này.
